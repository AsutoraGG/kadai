🎓 課題管理アプリ

Supabaseを使ってクラウドに課題を保存します。複数PCからアクセスできます。
初回のみ以下の設定が必要です。

1
Supabaseプロジェクトを作成
supabase.com で無料アカウントを作り、新しいプロジェクトを作成してください。
2
SQLでテーブルを作成
ダウンロードした supabase_setup.sql の内容を、ダッシュボードの SQL Editor に貼り付けて実行してください。
3
接続情報を入力
Project Settings → API から Project URL と anon public key をコピーして貼り付けてください。
